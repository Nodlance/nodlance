## Design Concept (Minimalist Cluster Delta)

- **Three Nodes (Vertices)**: Minimalist dots representing the high-availability database cluster (Primary + Replicas).
- **Interconnect Lines**: Cluster network replication and discovery topology.
- **Center Lance**: Sharp upward arrow / spearhead representing safety gates, proactive protection, and operations.
- **Color Palette**:
  - Lance Accent: `#38BDF8` / `#0284C7` (Electric Blue / Azure)
  - Node Vertices: `#F8FAFC` (Slate White)
  - Topology Lines: `#94A3B8` / `#64748B` (Muted Slate)
  - Dark Canvas: `#0F172A`
